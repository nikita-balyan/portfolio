Network Traffic Analyzer

Network security / threat detectionHome lab

A Python tool that captures live packets and flags IP addresses sending unusually many packets, built to practise how SOC analysts spot suspicious traffic.

PythonScapyUbuntuVirtualBox

View GitHub

Details
Challenge
Understand what normal and suspicious network activity looks like at packet level, and produce output a SOC analyst could review.
Environment
Ubuntu virtual machine in VirtualBox, with Python and Scapy.
What I built
A real-time capture tool that records source and destination IP, protocol and port, with TCP/UDP analysis across common ports (443, 53, 22). It writes timestamped CSV incident reports for log-style review.
What I tested
I ran it on traffic generated by browsing with Mozilla Firefox inside the VM. Threshold detection flags any IP exceeding 15 packets, a simple simulation of brute-force and DDoS-style patterns.

CyberGuardian

Threat detection / phishing & scam analysisAcademic project, deployed

A web app that analyses suspicious URLs, messages and QR codes and returns a risk score with a plain-language explanation. It targets scams aimed at college students, such as fake internships and payment requests.

PythonFastAPIReactPostgreSQL (Supabase)DockerXGBoost

View GitHub Live demo (add link)

Details
Challenge
Scam links and messages are hard for students to judge. I wanted a tool that shows which signals made something look risky, such as URL reputation, SSL validity and urgency or authority language.
Environment
FastAPI backend, React + Vite + Tailwind frontend, Supabase PostgreSQL, Docker Compose. Built for my Software Engineering course, with a project report and API documentation.
What I built
URL, message and QR analysis. The risk score combines rule-based heuristics, an XGBoost classifier trained on 12 lexical URL features, and threat-intelligence lookups (Google Safe Browsing, URLhaus). A Gemini API layer writes the explanation.
What I tested
Rate limits, input validation (size and length limits) and 65 automated tests passing.
Security concepts
Phishing indicators, threat intelligence, risk scoring, rate limiting, input validation, audit logging.
